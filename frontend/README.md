# Frontend

Minimal Next.js skeleton for the Music Show Wins frontend. Product design and
feature implementation are intentionally pending; see [`style.md`](style.md).

## Stack

- Next.js 16.3.1 with the App Router and TypeScript
- Tailwind CSS 4
- shadcn/ui (Base UI, neutral CSS-variable theme)
- pnpm

## Local development

```text
pnpm install
pnpm dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

## Checks

```text
pnpm lint
pnpm typecheck
pnpm build
```
